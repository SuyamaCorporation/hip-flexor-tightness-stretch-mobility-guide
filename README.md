# 腸腰筋タイトネス ストレッチ&モビリティガイド

デスクワーク由来の股関節屈曲タイトネスを評価するトーマステスト自己チェックと、腸腰筋・大腿直筋対象のストレッチ6種（3レベル）を提供するアプリです。結果に応じた推奨レベルの表示と週次可動域トラッキングを備えています。

## 機能
- トーマステスト自己チェック（3ステップ図解・判定基準）
- テスト結果選択（陰性/陽性軽度/陽性重度）に応じた推奨ストレッチ表示
- 3レベルのストレッチライブラリ（Level 1基礎 / Level 2中級 / Level 3上級）
- 各ストレッチの実施方法・よくあるエラー・所要時間
- カスタムルーティンビルダー（最大6種・合計時間自動計算）
- 股関節屈曲角度の週次記録と改善グラフ（SVG折れ線）
- 座りすぎ対策のヒントパネル
